根據 ATM90E26 的規格書（Source、），其暫存器表主要分為**狀態暫存器**、**校正設定暫存器**、**電能累計暫存器**以及**測量數據暫存器**四大類。

以下整理完整的暫存器清單：

### 1. 狀態與特殊暫存器 (Status and Special Registers)
這組暫存器用於系統重置、狀態監控與特殊模式切換。

| 位址 (Hex) | 暫存器名稱    | 類型 | 功能說明                                                     |
| :--------- | :------------ | :--- | :----------------------------------------------------------- |
| **00H**    | **SoftReset** | W    | **軟體重置**；寫入 `789AH` 可重啟晶片。                      |
| **01H**    | **SysStatus** | R/C  | **系統狀態**；指示校驗碼錯誤、漏電線路變更、電壓驟降等狀態。 |
| **02H**    | **FuncEn**    | R/W  | **功能啟用**；設定電壓驟降或方向改變時是否觸發中斷。         |
| **03H**    | **SagTh**     | R/W  | **電壓驟降閥值**；配置偵測電壓不足的標準。                   |
| **04H**    | **SmallPMod** | R/W  | **小功率模式**；寫入 `A987H` 進入此模式進行功率偏移校正。    |
| **06H**    | **LastData**  | R    | **最後讀寫值**；存儲上一次 SPI/UART 操作的 16 位元數據。     |

---

### 2. 計量校正與配置暫存器 (Metering Calibration & Configuration)
用於設定電表常數、啟動電流閥值及 L/N 線路的初步校正。

| 位址 (Hex)  | 暫存器名稱          | 類型 | 功能說明                                                         |
| :---------- | :------------------ | :--- | :--------------------------------------------------------------- |
| **08H**     | **LSB**             | R/W  | **RMS/功率低位字元**；用於擴展測量數據的精度。                   |
| **20H**     | **CalStart**        | R/W  | **計量校正啟動指令**；`5678H` 開始校正，`8765H` 檢查配置正確性。 |
| **21H/22H** | **PLconstH/L**      | R/W  | **PL_Constant 高/低位**；與電表脈衝常數相關的硬體常數。          |
| **23H/24H** | **Lgain/Lphi**      | R/W  | **L 線路校正增益與相位**。                                       |
| **25H/26H** | **Ngain/Nphi**      | R/W  | **N 線路校正增益與相位**。                                       |
| **27H/28H** | **PStartTh/PNolTh** | R/W  | **有效電能啟動/無效功閥值**；低於此值不計電。                    |
| **29H/2AH** | **QStartTh/QNolTh** | R/W  | **無效電能啟動/無效功閥值**。                                    |
| **2BH**     | **MMode**           | R/W  | **計量模式配置**；設定增益、高通濾波器與防竊電模式。             |
| **2CH**     | **CS1**             | R/W  | **校驗碼 1**；暫存器 21H~2BH 的校驗結果。                        |

---

### 3. 測量校正暫存器 (Measurement Calibration Registers)
專用於 RMS 電壓、電流及平均功率的細部偏移與增益修正。

| 位址 (Hex)  | 暫存器名稱            | 類型 | 功能說明                                  |
| :---------- | :-------------------- | :--- | :---------------------------------------- |
| **30H**     | **AdjStart**          | R/W  | **測量校正啟動指令**。                    |
| **31H**     | **Ugain**             | R/W  | **電壓有效值增益**。                      |
| **32H/33H** | **IgainL/IgainN**     | R/W  | **L/N 線路電流有效值增益**。              |
| **34H**     | **Uoffset**           | R/W  | **電壓偏移補正**。                        |
| **35H/36H** | **IoffsetL/IoffsetN** | R/W  | **L/N 線路電流偏移補正**。                |
| **37H~3AH** | **P/QoffsetL/N**      | R/W  | **L/N 有效/無效功率偏移補正**。           |
| **3BH**     | **CS2**               | R/W  | **校驗碼 2**；暫存器 31H~3AH 的校驗結果。 |

---

### 4. 電能與測量數據暫存器 (Energy & Measurement Registers)
開發時最常讀取的即時電力參數暫存器。

**電能累計 (讀取後自動清零)：**
*   **40H~42H**：AP/AN/ATenergy (**有效電能**：正向、反向、絕對值)。
*   **43H~45H**：RP/RN/RTenergy (**無效電能**：正向、反向、絕對值)。
*   **46H**：**EnStatus** (計量狀態，含線路方向指示)。

**即時測量值：**
*   **48H/49H**：**Irms / Urms** (L 線電流 / 電壓有效值)。
*   **4AH/4BH**：**Pmean / Qmean** (L 線平均有效功率 / 無效功率)。
*   **4CH/4DH**：**Freq / PowerF** (頻率 / L 線功率因數)。
*   **4EH/4FH**：**Pangle / Smean** (L 線電壓電流相位角 / 視在功率)。
*   **68H**：**Irms2** (N 線路即時電流有效值)。
*   **6AH~6FH**：**Pmean2 / Qmean2 / PowerF2 / Pangle2 / Smean2** (N 線路對應電力參數)。

**💡 讀取秘訣**：在讀取如 `Irms` 或 `Pmean` 等數值後，可以緊接著讀取 `LSB (08H)` 暫存器，這會鎖定該次測量的額外低位元數據，將測量精度提升至 32 位元等級。
