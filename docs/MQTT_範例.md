根據開發式樣書（來源），TJ3-nRF 系統的 MQTT 通訊架構採用固定的 **Topic** 與 **Payload** 結構。

### 通用規則與格式
*   **Topic (主題)**：
    *   發送到設備：`kyosvr/[MainID]/[PeriID]/cmd`。
    *   設備回傳：`kyokuto/[MainID]/[PeriID]/[識別碼]`。
*   **Payload (電文)**：固定格式為 `\x02 [PeriID] [識別碼] [序號] [端末號] [MainID] [數據內容] \x03`。
*   **預設 ID**：以下範例假設親機 (Gateway) 為 `GW0001`，子機 (Peripheral) 為 `PE0002`，序號為 `01`，端末號為 `02`（00 為本體）。

---

### 一、 警報與事件類別 (Device 發送)
當發生異常時，設備主動 Publish 到 `kyokuto/` 主題。

1.  **AD (接點警報)**：
    *   `\x02PE0002AD0102GW000111\x03`（通道 1 警報）。
2.  **EB / EC (輕/重漏電警報)**：
    *   `\x02PE0002EB0102GW000111+0150\x03`（通道 1 輕漏電 150mA）。
    *   `\x02PE0002EC0102GW000110+0000\x03`（重漏電解除）。
3.  **BH / BI (微地絡/地絡警報)**：
    *   `\x02PE0002BH0102GW0001110040+0050\x03`（地絡警報，閥值 40mA，測值 50mA）。
4.  **FE (過負荷警報)**：
    *   `\x02PE0002FE0102GW000101105000050600\x03`（CH1 發生警報，設定 500A，時間 5 分，現值 600A）。
5.  **AB / AC (停電/復電通報)**：
    *   `\x02PE0002AB0102GW0001\x03`（停電）。
    *   `\x02PE0002AC0102GW0001\x03`（復電）。

---

### 二、 定期通報與狀態類別 (Device 發送)
1.  **FA (測量值定期通報)**：
    *   `\x02PE0002FA0102GW0001122215300010.000...0050\x03`（日期 12/22 15:30，含 6 通道電流與地絡電流）。
2.  **AE (死活監視/健康檢查)**：
    *   `\x02PE0002AE0102GW00011530000210\x03`（15:30:00，連接子機 2 台，狀態為已連線）。
3.  **GA / GB / GC (需量定期/注意/限界)**：
    *   `\x02PE0002GA0102GW000122153030050000000\x03`（22日 15:30，30分電力量 500kWh）。

---

### 三、 Polling 要求與回應 (Request/Response)
由雲端 (Server) 發送 `cmd` 要求，設備回傳對應識別碼主題。

| 識別碼    | 功能說明           | Request 範例 (kyosvr/.../cmd)      | Response 範例 (kyokuto/.../[ID])           |
| :-------- | :----------------- | :--------------------------------- | :----------------------------------------- |
| **PA**    | **需量現在值**     | `\x02PE0002PA0102GW0001\x03`       | `\x02PE0002PA990102GW000112300500...`      |
| **PB/PC** | **需量設定/變更**  | `\x02PE0002PB0102GW0001\x03`       | `\x02PE0002PB990102GW00011000...`          |
| **PF**    | **需量通報控制**   | `\x02PE0002PF0102GW00012\x03`      | `\x02PE0002PF0102GW00010\x03` (0:成功)     |
| **PG**    | **子機連線資訊**   | `\x02PE0002PG0102GW0001\x03`       | `\x02PE0002PG0102GW0001002...[子機清單]`   |
| **PH**    | **漏電即時資訊**   | `\x02PE0002PH0102GW0001\x03`       | `\x02PE0002PH0102GW000100100020...01`      |
| **PI/PJ** | **輕漏電閥值設定** | `\x02PE0002PI0102GW0001\x03`       | `\x02PE0002PI0102GW000100500050...`        |
| **PK/PL** | **重漏電閥值設定** | `\x02PE0002PK0102GW0001\x03`       | `\x02PE0002PK0102GW000101000100...`        |
| **PN**    | **30分電力量**     | `\x02PE0002PN0102GW00012412221500` | `\x02PE0002PN0102GW00012412221500050000`   |
| **PO/PP** | **時間確認/變更**  | `\x02PE0002PO0102GW0001\x03`       | `\x02PE0002PO0102GW00012412221530\x03`     |
| **PQ**    | **軟體版本**       | `\x02PE0002PQ0102GW0001\x03`       | `\x02PE0002PQ0102GW0001S251009\x03`        |
| **PU/PV** | **Io/Ior設定**     | `\x02PE0002PU0102GW0001\x03`       | `\x02PE0002PU9902GW00010101...[設定清單]`  |
| **PW**    | **相位與Io值**     | `\x02PE0002PW0102GW0001\x03`       | `\x02PE0002PW990102GW00010150+0900...`     |
| **QA~QD** | **漏電判定時間**   | `\x02PE0002QA0102GW0001\x03`       | `\x02PE0002QA0102GW0001001005...[ot/ut]`   |
| **QE~QI** | **名稱資訊**       | `\x02PE0002QF0102GW0001\x03`       | `\x02PE0002QF0102GW0001TJ3-DEVICE\x03`     |
| **QJ/QK** | **無線(DECT)設定** | `\x02PE0002QH0102GW0001\x03`       | `\x02PE0002QJ0102GW00010[CONFIG_...]\x03`  |
| **QL/QM** | **4G/LTE 設定**    | `\x02PE0002QL0102GW0001\x03`       | `\x02PE0002QL0102GW0001172.31...[IP/Port]` |

**💡 註記**：部分 Polling 回應電文會加入固定填充碼 `99` 或修改識別碼（如要求 QF 回應 QE），請嚴格參照各節電文格式表。各類設定變更（如 PP、PC、PJ、PL、PV 等）若成功執行，其回應電文中的 `Result Code` 通常為 **'0'**。
