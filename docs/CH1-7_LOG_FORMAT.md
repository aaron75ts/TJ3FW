```text
AC 1 PH
CH1: Io=****mA, Ior=****mA, PH=*** º
CH2: Io=****mA, Ior=****mA,  PH=*** º
CH3: Irms=**.***A,  PH=*** º
CH4: Irms=**.***A,  PH=*** º
CH5: Irms=**.***A,  PH=*** º
CH6: Irms=**.***A,  PH=*** º

```
