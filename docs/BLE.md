
# BLE 透過模式指令 (OP_CODE)
在 BLE 「透過模式」下，外部設備（如手機 APP）透過傳送固定結構的封包與本機通訊。封包結構通常為：`[STX(02)] [LEN] [OP_CODE] [DATA...] [ETX(03)] [CRC]`。

| OP_CODE (Hex) | 功能名稱          | 說明                                                   | 來源 |
| :------------ | :---------------- | :----------------------------------------------------- | :--- |
| **0x66**      | Io/Ior 資訊取得   | 讀取指定通道 (CH1-6) 的漏電電流、相位角與警報界限。    |      |
| **0xF6**      | AI 即時電流取得   | 取得 6 個通道的即時電流數據與 DI 警報狀態位元。        |      |
| **0xD8**      | 最高電流資訊取得  | 取得過去 3 個月內各通道的最高電流值及其發生時間。      |      |
| **0xF9**      | 需量數據取得      | 取得目前電力、預測電力、30 分鐘需量值及各硬體版本。    |      |
| **0xD5**      | 裝置名稱變更      | 設定藍牙顯示名稱（DeviceName）與設置場所（Location）。 |      |
| **0xD6**      | 裝置名稱取得      | 讀取目前的藍牙顯示名稱與設置場所。                     |      |
| **0xE5**      | 通訊/需量設定變更 | 修改 Server IP、LTE APN、需量目標值、脈衝係數等。      |      |
| **0xE6**      | 通訊/需量設定取得 | 讀取目前的通訊與需量相關參數設定。                     |      |
| **0xB5**      | AI 設定變更       | 修改各通道的監測方式 (Io/Ior)、相位補正與判定時間。    |      |
| **0xB6**      | AI 設定取得       | 讀取目前的 AI 監測方式、相位與判定時間設定。           |      |
| **0xA5**      | MQTT 設定變更     | 設定雲端連線的 MQTT Client ID 與 Server URL 位址。     |      |
| **0xA6**      | MQTT 設定取得     | 讀取目前的 MQTT 連線參數設定。                         |      |
