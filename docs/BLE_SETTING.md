根據開發式樣書，App 端（Central）設定 TJ3 系統時，封包必須遵循固定結構：`[STX(02)] [LEN_L] [LEN_H] [OP_CODE] [DATA...] [ETX(03)] [CRC1] [CRC2]`。

以下整理所有核心設定項及其完整封包範例：

### 1. AI 監控與漏電設定 (OP Code: 0xB5)
此設定用於配置 6 個通道的監控邏輯，數值多採 **Little Endian (LSB)** 格式。

| 設定項目       | 內容說明                                  | 範例數據               |
| :------------- | :---------------------------------------- | :--------------------- |
| **警報類型**   | 6 CH：Io('3'), Ior自動('1'), Ior手動('2') | `33 33 33` (全 Io)     |
| **相位設定**   | 6 CH：單相('1') 或 三相('3')              | `11 11 11` (全單相)    |
| **補正相位角** | 6 CH：0°('0') ~ 150°('5')                 | `00 00 00` (全 0°)     |
| **限值與時間** | 輕/重漏電閥值 (mA)、判定/復歸時間 (秒)    | 100mA, 5秒             |
| **ZCT 比值**   | 6 CH：4500:1('0') 或 2000:1('1')          | `00 00 00` (全 4500:1) |

**完整封包範例 (HEX)：**
`02 6D 00 B5 01 333333333333 111111111111 000000000000 [Thresholds/Times...] 303030303030 03 [CRC1] [CRC2]`

---

### 2. 通訊與需量設定 (OP Code: 0xE5)
此處所有 HEX 值統一採用 **Little Endian**。

| 設定項目        | 內容說明                                     | 範例數據                      |
| :-------------- | :------------------------------------------- | :---------------------------- |
| **伺服器 IP**   | 4-byte HEX (點分十進位)                      | `AC 1F 21 FA` (172.31.33.250) |
| **伺服器 Port** | 2-byte HEX (Little Endian)                   | `5B 07` (1883)                |
| **需量警報**    | 目標電力 (Alarm 1) 與 限界電力 (Alarm 2)     | 50kW, 60kW                    |
| **脈衝係數**    | 4-byte HEX (Little Endian)，定義度數換算比例 | `0C 00 00 00` (0.0012)        |

**完整封包範例 (HEX)：**
`02 79 00 E5 AC1F21FA 5B07 [Modem_IP/APN...] [Demand_Params...] 03 [CRC1] [CRC2]`

---

### 3. MQTT 客戶端設定 (OP Code: 0xA5)
設定連線至 AWS IoT Core 所需的識別碼與網址。

| 設定項目            | 長度要求           | 範例數據                                        |
| :------------------ | :----------------- | :---------------------------------------------- |
| **MQTT Client ID**  | 固定 16-byte ASCII | `TJ3_NODE_000001`                               |
| **MQTT Server URL** | 固定 80-byte ASCII | `a1b2c3d4e5f6.iot.jp-northeast-1.amazonaws.com` |

**完整封包範例 (HEX)：**
`02 64 00 A5 [16-byte ID] [80-byte URL] 03 [CRC1] [CRC2]`

---

### 4. 設備名稱與位置 (OP Code: 0xD5)
用於手機 App 識別設備及標註安裝地點。

| 設定項目          | 長度要求           | 範例數據              |
| :---------------- | :----------------- | :-------------------- |
| **Device Name**   | 固定 20-byte UTF-8 | `Floor1_Main_Panel`   |
| **Location Name** | 固定 60-byte UTF-8 | `Factory_A_Section_1` |

**完整封包範例 (HEX)：**
`02 54 00 D5 [20-byte Name] [60-byte Location] 03 [CRC1] [CRC2]`

---

### 5. 硬體計量增益 (Meter Config 特徵值)
直接寫入 UUID `...8c02` 特徵值，不使用 OP Code 封裝。

| 設定項目     | 內容說明                | 範例數據            |
| :----------- | :---------------------- | :------------------ |
| **CT Ratio** | 變流器比例設定          | `01 03 E8` (1/1000) |
| **CH_Igain** | ATM90E26 內部增益校正值 | `00 04` (Gain=4)    |

**完整數據範例 (Raw 20 bytes)：**
`[CT_Ratios...] [CH_Igains...] [Padding...]`

**💡 開發提醒：**
在發送任何 **WRITE** 封包前，請確認已長按設備上的 **"S" 鈕 3 秒**，否則設備會拒絕更新設定。
