根據《TJ3 測電功能說明》及 ATM90E26 規格書，算出 CH1-CH6 電流值的步驟如下：

### 1. 確定硬體對應關係
首先，您需根據接線確認讀取的暫存器與通道位址：
*   **CH1 / CH3 / CH5 (N線)**：讀取 **Reg[0x68]** ($Irms2$)。
*   **CH2 / CH4 / CH6 (L線)**：讀取 **Reg[0x48]** ($Irms$)。

### 2. 電流計算公式
實際量測到的電流值需透過以下公式換算：
$$\text{實際電流值} = \frac{\text{暫存器讀值} \times \text{Ratio}}{\text{Igain 調整值}}$$

*   **暫存器讀值**：ATM90E26 的電流格式為 $XX.XXX$，故原始讀值應先除以 $1000$ 換算為基本安培數。
*   **Ratio (CT 比值)**：
    *   若使用 **ZCT**，Ratio 固定為 $400$ ($2000/5$)。
    *   若使用 **CT**，則依設定輸入（例如 $1000/10 = 100$）。
*   **Igain 調整值**：這是為了使讀取值與實際儀器量測值一致而設定的校正係數。

### 3. 計算範例
假設讀取 CH2（L線）的 Reg[0x48] 得到 `0x531A` (21274)，且 Ratio 為 $100$：
1.  **基本換算**：$21274 / 1000 = 21.274\text{ A}$。
2.  **套用 Ratio**：$21.274 \times 100 = 2127.4\text{ A}$。
3.  **校正**：再除以您的軟體校正係數（$Igain$）即得最終值。

### 4. 漏電電流 Ior 額外運算
若該通道設定為 **ZCT** 模式測量漏電，還需結合相位角（Reg[0x4E] 或 0x6E）算出阻抗分量 $Ior$：
*   **單相**：$Ior = Io \times \cos(\phi + \alpha)$。
*   **三相**：$Ior = Io \times \frac{\sin(\phi + \alpha)}{\cos 30^\circ}$。
    *   $\phi$：M90E26 讀到的相位角。
    *   $\alpha$：手動設定的補償角。

**💡 提示**：您目前讀到的數值（如 `0x531A`）若在未掛載負載時出現，通常代表硬體參考電位（Vref）尚未穩定或是環境雜訊干擾。
